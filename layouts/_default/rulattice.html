What it translates

Languages
Sentinel and Defender KQL, Splunk SPL, Cortex XQL, CrowdStrike CQL and Falcon LogScale, in any direction.
Filters
And, or, not, equality and numeric comparisons, contains, starts with, ends with, lists, regex and wildcards. Each platform's case sensitivity is preserved, not assumed.
Aggregation
Count, distinct count, sum, min, max and average by fields, with thresholds, sort and limit after the aggregation still pointing at the right column.
Computed fields
extend, eval, alter and :=, renames, and scalar let constants, using one shared function set. SPL's 1-based substr becomes KQL's 0-based substring without you thinking about it.
Event classes
Cortex ENUM constants become the target's native selector: Defender XDR tables, SecurityEvent 4688 or ASIM for Sentinel; Sysmon or Security log event codes for Splunk; Falcon event names; ECS fields for LogScale.
Field mapping
Optional. Picks names for the data source you choose, and reports every rename so you can check it.

What it refuses

If a construct has no exact equivalent on the target, Rulattice returns no output and names the construct. Joins, lookups, time bucketing and functions outside the shared set are refused today.

That is deliberate. A refusal costs you a minute. A confident, wrong translation costs you a detection that never fires.

How it checks itself

Every output is parsed again in the target language and compared with the source. When the meaning survives the trip, the check passes. Anything it had to adapt is listed by severity:

Caution
The output can return more events than the source, such as an OS filter the target has no column for.
Review
Correct as written, but depends on your data: a mapped field name, a data source, an index to narrow.
